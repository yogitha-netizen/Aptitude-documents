# Placement Preparation: Aptitude Practice

This repository contains the practice material used in my placement-preparation classes. It has two kinds of content:

1. **Weekly class questions**: the questions discussed in class each week, with solutions.
2. **Aptitude test papers**: full-length practice papers with answer keys and short explanations.

## Who is this for?

Students preparing for campus placement exams and company aptitude rounds. You can use it for self-practice, revision, or timed mock tests.

### Aptitude Papers (4 Sets)

| Set | Questions | Sections | Time |
|-----|-----------|----------|------|
| Set 1 | 20 | Quantitative (10) + Logical Reasoning (10) | 30 min |
| Set 2 | 20 | Quantitative (10) + Logical Reasoning (10) | 30 min |
| Set 3 | 20 | Quantitative (10) + Logical Reasoning (10) | 30 min |
| Set 4 | 20 | Quantitative (10) + Logical Reasoning (10) | 30 min |

- No question or question model is repeated across the four sets.
- Each question has four options with exactly one correct answer.
- Every set comes with an answer key and a short explanation for each answer.

**Marking scheme:** +1 for each correct answer, −0.25 for each wrong answer.

## Topics Covered

**Quantitative Aptitude:** profit and loss, simple and compound interest, time and work, pipes and cisterns, time-speed-distance, trains, boats and streams, ratio and proportion, averages, percentages, alligation, ages, probability, permutations and combinations, number system, mensuration, and algebra.

**Logical Reasoning:** number and letter series, coding-decoding, blood relations, direction sense, syllogisms, seating arrangements, clocks and calendars, Venn diagrams, inequalities, data sufficiency, puzzles, and analogies.

## How to Use

1. Download or clone this repository.
2. Attempt a paper within the given time without looking at the answer key.
3. Check your answers with the key and read the explanations for the ones you got wrong.
4. Revise the related weekly class questions and attempt the next set.
